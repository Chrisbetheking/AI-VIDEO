# Sticker source

The transparent PNG sticker assets in this folder are selected from Google Fonts' Noto Emoji image resources:

- Repository: https://github.com/googlefonts/noto-emoji
- Image resources: Apache License 2.0 (see bundled LICENSE-APACHE-2.0.txt)
- Local filenames are semantic aliases used by AI-VIDEO (house, key, warning, pin, etc.).

The assets are included as transparent PNGs and are overlaid without adding any background panel.
